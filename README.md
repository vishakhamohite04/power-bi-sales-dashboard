📊 Project Overview

An interactive Sales Analysis Dashboard built using Microsoft Power BI to explore sales performance and profitability.

DAX for KPI calculations

Data Modeling and Table Relationships

Data Visualization and Business Insights

Monthly Revenue and Profit Trends

Top 5 and Bottom 5 Countries by Revenue

Sales Channel Revenue Comparison

Revenue by Product Category

Revenue vs. Gross Profit by Category

To transform raw sales data into an interactive dashboard and develop practical skills in data analysis and business intelligence.
